Privacy Policy - Finance Tracker AI

Effective date: May 11, 2026

Overview

Finance Tracker AI helps users track personal expenses and recurring payments. We store sensitive API keys on backend infrastructure and do not embed provider secret keys in the mobile app.

Data We Process

  • Profile data: display name and email, when provided
  • Finance data: expenses, recurring expense entries, categories, and notes
  • AI inputs: user prompts and receipt text submitted for parsing or insights
  • Diagnostics: operational logs for app and server reliability

Where Data Is Stored

  • On device: local app storage for app state and fast startup
  • Cloud sync: Firebase for profile and finance state
  • AI processing: prompts and receipt text are sent to the app backend, then relayed to the configured AI provider

How We Use Data

  • Provide expense tracking functionality
  • Sync finance data between sessions and devices
  • Generate AI-based finance insights and structured receipt drafts
  • Detect and debug service failures

Data Sharing

We share data only with service providers required for app functionality, including Firebase, backend hosting providers, and AI processing providers. We do not sell personal data.

Data Retention

  • Local data remains on device until the user clears app data or removes the app.
  • Synced data remains until deleted by the user or app operator.
  • Server logs are retained for operational and security purposes for a limited period.

User Controls

  • Edit profile data in Settings
  • Delete individual expenses and recurring items
  • Export finance data from Settings
  • Clear local and synced finance data from Settings

Security

  • Provider API secrets are stored as server-side environment variables.
  • App-to-server calls use HTTPS.
  • Infrastructure access is restricted to authorized maintainers.

Children's Privacy

This app is not intended for children under 13.

Contact

For privacy questions, deletion requests, or support, visit Finance Tracker AI Support.
